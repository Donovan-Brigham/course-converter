How to use

  1. Open Find Course Sections in your scheduling system, run your search, then use Print → Save as PDF to export it.
  2. Drop the PDF above (or click Choose PDF(s)). You can add multiple departments at once — they'll be merged into one file.
  3. Click Convert to Excel. The spreadsheet downloads to your Downloads folder automatically.
  4. Columns: Course ID · Section # · Course Title · Component · Pattern · Start Time · End Time · Location (Room) · Instructor · Notes · Cap
Works in Chrome or Edge  ·  PDFs are cleared from memory after conversion  ·  No files are stored or uploaded
